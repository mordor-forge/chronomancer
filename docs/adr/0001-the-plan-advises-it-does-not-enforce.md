# The plan advises, it does not enforce

Version 0.1 blocked production writes outside an approved window. The owner's real work does not fit hard gates: estimates are conservative, priorities change during the day, and the owner often wants to run a card now. We decided that the plan is a shared picture and a set of easy moves, not a lock. A slot says when a card is expected to run. A clash is shown and explained, and nothing is refused because of it.

## Consequences

- A user who needs a hard gate must get it from another mechanism. The plan does not promise one.
